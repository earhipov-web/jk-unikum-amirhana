# ЖК «Уникум на Амирхана» — информационный сайт

Многостраничный сайт о жилом комплексе в Казани: главная с акциями и дашбордом, цены и услуги,
ипотека с калькулятором, расположение, отзывы с формой бесплатной консультации.

Это не официальный сайт застройщика. Данные собраны из открытых источников и лежат в `lib/data.ts`.

## Стек

Next.js 16 (App Router), TypeScript, Tailwind CSS 4, структура shadcn (`components/ui`), recharts.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

## Деплой

Сайт: https://jk-unikum-amirhana.netlify.app

Каждый пуш в ветку `main` запускает сборку и публикацию на Netlify. Ручной деплой из папки проекта:

```bash
netlify deploy --prod --build
```

## Заявки с формы

- На Netlify заявки сохраняются в закрытое хранилище Netlify Blobs, стор `leads`.
  Посмотреть список: `netlify blobs:list leads`, прочитать одну: `netlify blobs:get leads <ключ>`.
- Локально заявки пишутся в `data/leads.jsonl` (папка в `.gitignore`).

В заявках персональные данные — не выкладывайте их в репозиторий.
